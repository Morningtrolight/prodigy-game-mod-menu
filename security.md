## 🛠️ The Mod Menu Architecture

The tool is built to be user-friendly, even if you have never used a script before. Here is how it works.

### 1. The Injection Engine
The mod menu uses a lightweight JavaScript bookmarklet (or a browser extension). When you launch Prodigy, you click the bookmark. It injects a custom UI overlay directly into the game's DOM (Document Object Model). The UI is draggable, resizable, and does not interfere with the game's native controls.

### 2. The Feature Modules
The menu is organized into tabs. The **Player Tab** lets you modify your level, gold, and inventory. The **Pets Tab** lets you spawn any pet in the game, including exclusive membership pets. The **Battle Tab** gives you infinite health, one-hit kills, and auto-battle toggles. The **World Tab** unlocks all zones, allowing you to travel anywhere without completing the story quests.

### 3. The Safety Wrapper
We take account security seriously. The mod menu does not send your login credentials to any external server. All the modifications happen locally in your browser's memory. It includes a "Stealth Mode" that hides the UI with a hotkey (like `Shift + H`), making it easy to avoid detection if you are playing in a classroom or library.

## 🧠 Under The Hood: How The Mod Works

Prodigy is a web-based game built with JavaScript and WebGL. It communicates with its servers via WebSocket and REST API.

Our mod menu does not hack the servers. Instead, it intercepts the client-side JavaScript. When the game tries to load your inventory, the mod menu intercepts the response and injects extra items. When you enter a battle, the mod menu hooks into the battle loop and forces the enemy's health to zero.

Because the game trusts the client to calculate battle outcomes, the server accepts the result. This is a classic **Client-Side Trust Vulnerability**. We simply exploit the fact that the server does not re-calculate the math.
